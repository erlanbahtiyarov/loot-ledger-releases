# Loot Ledger

Репозиторий установщиков и обновлений, без данных кампаний и секретных ключей.

[Скачать Windows 0.12.0 и Android 0.5.0](https://github.com/erlanbahtiyarov/loot-ledger-releases/releases/tag/v0.12.0)

В Assets мастеру нужен Loot.Ledger_0.12.0_x64-setup.exe, игроку — loot-ledger-player-0.5.0.apk. Архивы Source code скачивать для установки не нужно. latest.json и .sig используются Windows updater.

## Начать игру

1. Мастер устанавливает EXE, создаёт профиль и кампанию, добавляет персонажей и игроков.
2. Мастер начинает сессию и создаёт приглашение в разделе игроков.
3. Игрок устанавливает APK, создаёт локальный профиль и сканирует приглашение внутри приложения. Телефон и компьютер должны находиться в общей Wi-Fi/LAN-сети.
4. Пошаговая помощь доступна внутри приложений и работает офлайн.

Windows 0.12.0 и Android 0.5.0. Мастеру нужен EXE, игроку — APK из Assets. Source code скачивать для установки не нужно.

## Изменения

- 31 значок для 11 типов предметов; отдельные символы для квестовых предметов, сокровищ, украшений и других категорий.
- Мастер выбирает значок в редакторе предмета. Выбор синхронизируется с Android и сохраняется офлайн.
- Исправлена ошибка Android: оружие больше не отображается как украшение. Для оружия с названием «Катана» автоматически выбирается катана, если мастер не назначил другой значок.
- Неопознанные предметы используют нейтральный значок без раскрытия скрытых данных.

## Как обновиться

Сохраните открытые формы и завершите сессию. В Windows проверьте обновления в настройках: updater проверяет подпись и создаёт резервную копию базы и текущего exe перед установкой. При ручной установке сначала создайте резервную копию в приложении, затем запустите EXE.

На Android сначала создайте ручную резервную копию профиля и установите APK поверх приложения. Не удаляйте приложение и не очищайте данные. Это тестовый APK с прежней debug-подписью; автоматическая зашифрованная копия профиля создаётся при первом запуске новой версии. Автоматического отката самого APK нет.

Для полного отображения значков обновите оба устройства. Формат SQLite — 10; поддержан импорт пакетов схем 8, 9 и 10. Откат Windows требует восстановления прежней базы вместе с прежним exe: старую программу нельзя запускать на новой схеме.

## Проверки

Typecheck, lint, 26 frontend-тестов и 42 Rust-теста прошли. Настоящий APK на Android 16 и тестовый Rust-мастер прошли 10 сквозных проверок: офлайн-создание, перезапуск, одобрение, отсутствие дубликатов, катана, синхронизация значка мастера, конфликт и отклонение правок. Аудит SQLite: целостность, внешние ключи и 6 инвариантов без нарушений. Production-сборки и подпись updater проверены, подмена файла и версии отклоняется.

Ранее полный публичный переход Windows 0.10.0 → 0.11.0 с сохранением данных и откатом прошёл. Переход именно 0.11.0 → 0.12.0 через установщик отдельно не прогонялся. Текущая проверка значков выполнена на изолированной тестовой базе, без открытия рабочей кампании.

Следующий этап: быстрый вход — запоминание входа игроком по желанию, выбор сохранённого персонажа и необязательный четырёхзначный PIN мастера. В этот выпуск он ещё не входит.
