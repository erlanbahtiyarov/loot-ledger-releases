# Loot Ledger

Репозиторий установщиков и обновлений, без данных кампаний и секретных ключей.

[Скачать Windows 0.13.0 и Android 0.6.0](https://github.com/erlanbahtiyarov/loot-ledger-releases/releases/tag/v0.13.0)

## Начать игру

1. Мастер устанавливает EXE, создаёт профиль и кампанию, добавляет персонажей и игроков.
2. Мастер начинает сессию и создаёт приглашение в разделе игроков.
3. Игрок устанавливает APK, создаёт локальный профиль и сканирует приглашение внутри приложения. Телефон и компьютер должны находиться в общей Wi-Fi/LAN-сети.
4. Пошаговая помощь доступна внутри приложений и работает офлайн.

Windows 0.13.0 и Android 0.6.0 (тестовый APK). Скачать файлы можно в Assets: мастеру нужен EXE, игроку — APK. Архивы Source code не нужны.

## Игроку

При входе или регистрации отметьте «Запомнить вход на этом устройстве». После перезапуска откроется список кампаний без повторного пароля. Нажмите «Войти за …», чтобы открыть сохранённого персонажа. Работает и без сети; синхронизация требует действующего доступа мастера.

Профиль остаётся зашифрованным. Ключ открытия защищён Android Keystore; пароль не сохраняется. Кнопка блокировки завершает вход и отключает запоминание. Восстановление профиля тоже отключает быстрый вход. Если ключ недоступен, остаётся вход по паролю.

## Мастеру

В настройках откройте «Быстрый вход мастера». Введите основной пароль, новый PIN из четырёх цифр и повторите PIN. При следующем входе достаточно PIN. Пять неверных попыток блокируют PIN на 5 минут, включая перезапуск программы; основной пароль остаётся доступен. Для отключения PIN сохраните настройку с основным паролем и пустыми полями PIN. Без включённого PIN используется обычный вход.

PIN хранится только как Argon2id hash; изменение настройки записывается в журнал без секрета. Схема SQLite — 11. Импорт кампаний схем 8–11 поддерживается.

## Обновление

Сохраните формы и завершите сессию. На Windows используйте проверку обновлений в настройках: подпись проверяется, перед установкой создаётся копия базы и текущего exe. Перед ручной установкой создайте резервную копию в приложении. Для отката восстанавливайте прежнюю базу вместе с прежней программой.

На Android создайте ручную копию профиля и установите APK поверх прежней версии, не удаляя приложение и данные. Сохранена прежняя debug-подпись тестовых APK. При первом запуске новой версии создаётся автоматическая копия зашифрованного профиля; автоматического отката самого APK нет.

## Проверки и границы

28 frontend-тестов, 42 существующих и 2 новых Rust-теста прошли; typecheck, lint и сборки без ошибок. Настоящий APK на эмуляторе Android 16 и тестовый Windows-мастер прошли 15 сквозных проверок: обновление APK 0.5.0 → 0.6.0 с резервной копией, PIN и основной пароль, запоминание и выход после перезапуска, выбор героя, офлайн-предметы, одобрение и конфликты. Аудит тестовой SQLite без нарушений.

Рабочая кампания пользователя не открывалась. Полный переход Windows 0.12.0 → 0.13.0 через публичный установщик отдельно не прогонялся. Проверка Android проведена на эмуляторе; новый быстрый вход на физическом телефоне ещё не проверялся.

Следующее согласованное дополнение — светлая и тёмная темы.
